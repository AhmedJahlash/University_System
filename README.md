# University Management System

A Python application for managing university data using SQLite.

## Features

- Add students
- Update students information
- Delete students
- Manage majors
- Manage courses
- Enroll students in courses
- Generate reports

## Technologies

- Python
- SQLite
- Git & GitHub

## Project Structure

- main.py : Main menu
- database.py : Database connection and tables
- students.py : Students management
- majors.py : Majors management
- courses.py : Courses management
- enrollments.py : Enrollment management
- reports.py : Reports
